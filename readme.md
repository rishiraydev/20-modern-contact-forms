# 20 Modern Contact Form Templates

A collection of 20 responsive, production-ready contact page templates built with semantic HTML5, modern CSS3, and vanilla JavaScript. Includes designs ranging from clean minimalist layouts to developer-focused terminals and bento grids.

## Live Demo

- Online Showcase: [https://rishiraydev.github.io/20-modern-contact-forms/](https://rishiraydev.github.io/20-modern-contact-forms/)
- Local Showcase: Open `index.html` in your browser.

## Features

- Zero dependencies: Pure HTML5, CSS3, and vanilla JavaScript.
- Fully responsive: Mobile-first responsive layouts across mobile, tablet, and desktop viewports.
- Form interactions: Focus animations, floating labels, submit states, and input validation included.
- Self-contained: Each template operates independently with its own markup, stylesheet, and script.
- Backend agnostic: Compatible with third-party form services (Formspree, Web3Forms, EmailJS) or custom backends (Node.js, PHP, Python, Go).

## Getting Started

### Local Setup

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/rishiraydev/20-modern-contact-forms.git
cd 20-modern-contact-forms
```

To run with a local development server:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

### Integration

To use an individual template:

1. Open the template folder (for example, `06-glassmorphism-contact/`).
2. Copy the HTML markup from `index.html` into your project.
3. Include the corresponding stylesheet (`css/style.css`) and script (`js/script.js`).
4. Update the form `action` URL to point to your backend or endpoint.

Example integration with an endpoint service:

```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
  <input type="text" name="name" required placeholder="Name">
  <input type="email" name="email" required placeholder="Email">
  <textarea name="message" required placeholder="Message"></textarea>
  <button type="submit">Send Message</button>
</form>
```
